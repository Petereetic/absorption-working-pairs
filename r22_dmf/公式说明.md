# R22–DMF 公式说明（命名与新增函数部分）

本模块的模型本身（泡点压力：Agarwal 1982 等温线 Antoine + PCHIP 插值；溶液焓：Fatouh et al. 1993）见代码文件头注与 `Borde1978_重建与核验.md`。本文件记录 2026-10-12 全库命名统一与新增函数的口径。

## 2026-10-12 全库命名统一与新增函数

旧名不留别名、彻底退场。**命名分账**：`Psol` = 溶液表面（平衡）蒸气压（原泡点压力函数），`Pref` = 纯制冷剂饱和压力，两者分账、不可互换。纯制冷剂饱和液焓为 `hliq`、饱和气焓为 `hgas`、潜热 `hlat = hgas - hliq`（两焓同基准才可减，本模块 hliq/hgas 同出 Fatouh 式、同基准）；溶液焓为 `hsol`，与 hliq 分账。本模块没有独立的纯 R22 Pref 函数（纯线即拟合面的 xi=1 等浓度线），Pref 改名不涉及。

### 新增：TdewByTsolXi（由溶液温度与浓度求露点温度）

定义（全库统一）：`TdewByTsolXi(Tsol, xi) = 模块 Tsat(Psol(Tsol, xi))`。本模块复合路径：`bubble_T(psol(T_C, xi), 1.0)`，即以拟合面的纯 R22 等浓度线（xi=1 端）评价溶液表面压力所对应的饱和温度。Python `tdew_by_tsol_xi`、C `R22DMF_TdewByTsolXi`、VBA `TdewByTsolXi_R22DMF`。单位 °C，xi 为 R22 质量分数（有效域 0.10–1.00，界外钳制），P 为 MPa（2026-10-14 起公开边界压力单位由 bar 改为 MPa：公开函数出口 ×0.1、入口 ×10 回 bar 进内部私有原生函数，拟合系数与公式不变）。DMF 视为不挥发。无解约定随 bubble_T：Python 返 None、C 返 NAN、VBA 返 #N/A。纯端锚：xi=1 时 Tdew 与 T 精确相等（构造）。

### 新增：TsolByHsol（hsol 的反函数）

`TsolByHsol(h, xi)` 满足 `hsol(TsolByHsol(h, xi), xi) = h`：对 hsol 在求解括号 T ∈ [−20, 95] °C（Fatouh 关联跨度 253.15–368.15 K）内二分 100 次（hsol 在固定 xi 下随 T 单调增）。Python `tsol_by_hsol`、C `R22DMF_TsolByHsol`、VBA `TsolByHsol_R22DMF`。h 超值域时：Python 返 None、C 返 NAN、VBA 返 Empty。验算往返误差 < 1e-6 K 量级。

## JavaScript 套（2026-10-28 新增）

- `r22_dmf.js` — 本模块的 JavaScript 实现，函数名与 Python 版逐一同名、无别名；xi 为 R22 质量分数、T 为 °C、压力公开边界 MPa（拟合内部保留 bar，只在边界换算），口径与本说明一致。共 9 函数：psol、bubble_T、xi_by_tsol_tdew、tdew_by_tsol_xi、tsol_by_hsol、hliq_R22、hgas_R22、h_DMF、hsol。
- 辖区纪律：明写辖区外抛 RANGE 错误（psol 的 T∈[−25, 120] °C 与 xi∈[0.10, 1.00]、bubble_T 与 xi_by_tsol_tdew 与 tdew_by_tsol_xi 的同域、焓函数族 hliq_R22/hgas_R22/h_DMF/hsol 的 T∈[−20, 95] °C、hsol 与 tsol_by_hsol 的 xi∈[0, 1]）；内部调用一律走 raw 私有版，公开检查不拦内部求值。Python 返 None 处返 null（bubble_T 超跨度、xi_by_tsol_tdew 无根、tdew_by_tsol_xi 无根、tsol_by_hsol 的 h 超值域）。设计性分账：Python 对 psol/bubble_T 的 xi 是钳制到 [0.10, 1.00] 后返值、焓多项式无温度检查，JS 公开版对辖区外抛 RANGE（源依据为 C 头注 Valid 范围）。迭代逐字镜像 Python（bubble_T 二分 60 次、xi_by_tsol_tdew 二分 80 次、tsol_by_hsol 二分 100 次）。
- 负记录一处：bubble_T(psol(120 °C, 0.5), 0.5) 经公开 MPa 往返（×0.1 再 ×10）后末位高约 1 ulp 出括号上沿，Python 与 JS 一致返 None/null；以精确 raw bar 值喂入则得 ≈120 °C。另注：xi>0.80 且 T>65 °C 为 Agarwal 实测数据之外的外推区（C 头注已标，R22 近/超临界），辖区内照算、不设 RANGE。
- 对数验证：与 Python 参考版逐点比对网格 378 点（值点 293、null 点 85），分类零不符，值点超差（相对差 >1e-9）零，最大相对差 1.95×10⁻¹⁵（bubble_T，P=2 MPa、xi=0.7）；RANGE 清单 29/29 全过；锚点 8/8 全过。锚点复现：Psol(30 °C, 0.5)＝0.3085704333879159 MPa、Psol(80 °C, 0.4)＝0.611968764304867 MPa、bubble_T(0.5 MPa, 0.5)＝50.87506064726861 °C、TdewByTsolXi(60 °C, 0.5)＝5.216384740970938 °C、XiByTsolTdew(90 °C, 20 °C)＝0.46742862131681195、hsol(30 °C, 0.5)＝130.26305191832645 kJ/kg、TsolByHsol 回代闭合 29.99999999999997 °C。
- 已上线 peterinno.com 试算页（API 路由 /api/calc/r22-dmf，视图五框：(T, xi) 状态点、(T) 纯组分焓、(P, xi) 泡点反解、xi_by_tsol_tdew、tsol_by_hsol；全 9 函数在 API 目录中）。
