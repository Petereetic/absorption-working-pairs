> 来源: M. Conde Engineering (2004)《Thermophysical Properties of NH3+H2O
> Solutions for the Industrial Design of Absorption Refrigeration Equipment》,

约定: `x` = 液相氨摩尔分数, `y` = 气相氨摩尔分数, `T` 单位 K。
返回 SI 单位;`pc_sol` 为 bar(书中原单位)。
`T*` 为对应状态温度: θ = T/Tc,sol(x), T\*NH3 = θ·Tc,NH3, T\*H2O = θ·Tc,H2O。

## §6 饱和液相比热 [kJ/(kg K)]

Cp_m = x·Cp_NH3(T\*NH3) + (1−x)·Cp_H2O(T\*H2O),
Cp(T\*) = A_cp + B_cp/τ, τ = 1 − T\*/Tc。

## §7 饱和液相导热 [W/(m K)]

λ_m = x·λ_NH3(T\*) + (1−x)·λ_H2O(T\*);
纯氨: λ = Σ AᵢTⁱ [mW/(m K)], A = (890.2275, −0.69235, −2.4010e−3, 0);
纯水: 附录 A。

## §8 饱和液相动力黏度 [Pa s]

ln η_m = x·ln η_NH3(T\*) + (1−x)·ln η_H2O(T\*) + Δη,
Δη = (0.534 − 0.815·T/Tc,H2O)·F(x),
F(x) = 6.38(1−x)^1.125·x·(1−e^{−0.585x(1−x)^0.18})·ln(η_NH3^0.5·η_H2O^0.5),
其中 η 取 μPa s(由量级验证确定;若取 Pa s 则 F(x) 符号/量级错误)。

## §9 表面张力 [N/m]

σ_m = x·σ_NH3(T\*) + (1−x)·σ_H2O(T\*) + Δσ,
σ = σ₀(1+bτ)τ^μ, Δσ = −(σ_H2O − σ_NH3)·F(x),
F(x) = 1.442(1−x)[1−e^{−2.5x⁴}] + 1.106x[1−e^{−2.5(1−x)⁶}]。

## §10 饱和液相密度 [kg/m³]

ρ_m = x·ρ_NH3(T\*) + (1−x)·ρ_H2O(T\*) + Δρ,
Δρ = x(1−x)(1 − A·x)·√(ρ_NH3·ρ_H2O),
A = Σ A1ᵢT‡ⁱ + (Σ A2ᵢT‡ⁱ)/x, T‡ = T/Tc,H2O。
实现中写成 A·x = x·ΣA1ᵢT‡ⁱ + ΣA2ᵢT‡ⁱ,避免 x=0 奇点。

## §11 质扩散系数 [m²/s] (修正 Wilke–Chang)

D = 117.282e−18·T·√(ψ_sol·M_sol) / (η_sol·Ṽ^0.6),
ψ_sol、M_sol 摩尔分数加权;ψ_NH3=1.7, ψ_H2O=2.6;
M_NH3=17.03, M_H2O=18.0152 g/mol;
Ṽ = M_NH3[g/mol]/ρ_NH3(T)[kg/m³];η_sol 取 §8 [Pa s]。

## §12 饱和气相导热 [W/(m K)]

Wassiljewa–Mason–Saxena 混合规则。
纯氨蒸气: λ = Σ Aᵢ[ln(1/τ)]ⁱ [mW/(m K)], τ = 1 − T/Tc,NH3,
A = (−0.48173, 20.04383, 0, 0);纯水蒸气: 附录 A。

## §14 饱和气相密度 [kg/m³]

ρ_m = y·ρ_NH3(T\*) + (1−y)·ρ_H2O(T\*) + Δρ,
Δρ = A(1−y)^B(1−e^{Cy^D})·Δρmax, Δρmax = e^{J−K/T‡},
A=82.0, B=0.5, C=−0.05, D=2.75, J=9.952, K=3.884, T‡=T/Tc,H2O。

## §15 饱和气相比热 [kJ/(kg K)]

Cp_m = y·Cp_NH3(τ) + (1−y)·Cp_H2O(τ),
Cp(τ) = A + Bτ^{−1/3} + Cτ^{−2/3} + Dτ^{−5/3} + Eτ^{−7.5/3},
τ = 1 − T/Tc,sol(y)。

## 附录 A: IAPWS 水导热系数 (1998 工业用公式)

λ = λ₀(T̄) + λ₁(ρ̄) + λ₂(T̄,ρ̄) [W/(m K)],
T̄ = T/647.26 K, ρ̄ = ρ/317.7 kg/m³, λ\* = 1.0 W/(m K)。

λ₀(T̄) = √T̄·Σ(j=0..3) L_{0,j}·T̄ʲ,
λ₁(ρ̄) = L_{1,0} + L_{1,1}ρ̄ + L_{1,2}·exp[L_{1,3}(ρ̄+L_{1,4})²],
λ₂ = (L_{2,0}/T̄¹⁰ + L_{2,1})ρ̄^1.8·exp[L_{3,0}(1−ρ̄^2.8)]
   + L_{2,2}·Λ₀·ρ̄^Λ¹·exp[(Λ¹/(1+Λ¹))(1−ρ̄^(1+Λ¹))]
   + L_{2,3}·exp(L_{3,1}T̄^1.5 + L_{3,2}/ρ̄⁵),
Λ₀ = 1/ΔT̄ (T̄≥1) 或 10.0932/ΔT̄^0.6 (T̄<1),
Λ¹ = 2 + 0.0822994/ΔT̄^0.6, ΔT̄ = |T̄−1| + 0.00308976。

|---|---|---|---|---|---|---|
| 0 | 0.0102811 | 0.0299621 | 0.0156146 | −0.00422464 | 0 | 0 |
| 1 | −0.397070 | 0.400302 | 1.060000 | −0.171587 | 2.392190 | 0 |
| 2 | 0.0701309 | 0.0118520 | 0.00169937 | −1.0200 | 0 | 0 |

**重要更正**:书中总式印刷为 λ̄ = λ̄₀×λ̄₁×λ̄₂,系排印错误。
证据: (1) 乘法在稀薄气体极限(ρ̄→0,λ₁→有限值?实则λ₁→L_{1,0}+L_{1,2}e^{...}≠0…
更直接地,ρ̄→0 时 λ₂→0?不,λ₂→L_{2,3}·exp(L_{3,1}T̄^1.5)→−1.02·e^{...}≠0;
总之乘法不满足 λ(ρ→0)=λ₀ 气体极限);(2) 唯有加法在 298.15K/997kg/m³
给出 0.6075 W/(m K),与验证点 0.6077 吻合;(3) 与 IAPWS 1998 原文及
XSteam 开源实现逐项一致。

验证: 293.15K/997kg/m³ → 0.59810 W/(m K) (参考 0.59801);
298.15K/997kg/m³ → 0.60745 W/(m K) (参考 0.60771)。

## 附录 B: IAPWS 水动力黏度 (工业用公式)

η = η\*·η̄₀(T̄)·η̄₁(T̄,ρ̄) [Pa s], η̄₂ = 1(书中说明临界增强可忽略),
T̄ = T/647.226 K, ρ̄ = ρ/317.763 kg/m³, η\* = 55.071e−6 Pa s。

η̄₀ = √T̄·(Σ(i=0..3) HᵢT̄^{−ⁱ})⁻¹,
H = (1.000, 0.978197, 0.579829, −0.202354);
η̄₁ = exp[ρ̄·Σ(i=0..5)Σ(j=0..6) G_{i,j}(T̄⁻¹−1)ⁱ(ρ̄−1)ʲ],
G 表见代码(已与原表逐值核对)。

验证: 293.15K/998.2kg/m³ → 1.0016e−3 Pa s (参考 1.002e−3)。

## 附录 C: Fenghour et al.(1995) 氨黏度

η(ρ,T) = η₀(T) + Δη(ρ,T) (+Δηc,书中未给系数,取 0) [μPa s], ρ: mol/L。

η₀(T) = 2.1357·√T·√M/(σ²·ζ), ζ = exp[Σ(i=0..4) aᵢ(lnθ)ⁱ], θ = T/386.0,
σ = 0.2957 nm, M = 17.03 g/mol,
a = (4.99318220, −0.61122364, 0, 0.18535124, −0.11160946)。

Δη = ρ·B₁ + Σ(i=2..4) ρⁱ·Σ(j=0..4) d_{i,j}θ^{−ʲ},
B₁ = 0.6022137·η₀·σ³·Σ(i=0..12) cᵢ(θ^0.5)^{−ⁱ},
c = (−1.7999496, 46.692621, −534.60794, 3360.4074, −13019.164,
33414.230, −58711.743, 71426.686, −59834.012, 33652.741,
−12027.350, 2434.8205, −208.07957),
d 表见代码(Table 5 已核对)。

**排印说明**:书中 Δη 求和内印刷为 ρ,按 Fenghour 1995 原文及 Table 5
列标(i=2,3,4)应为 ρⁱ;按 ρ 实现会使 Fig.12 差一个量级,故取 ρⁱ。

验证: 293.15K 饱和氨液(ρ≈610 kg/m³) → 0.138 mPa s (参考 ~0.13)。
