# 左桂兰 2009 硕士论文「可编程清单」

**文献**：左桂兰《离子液体型热泵新工质的性质研究》，大连理工大学硕士学位论文，导师赵宗昌，2009 年。源文件为作者藏本扫描件（85 页纯扫描，无文本层；本清单全部数据由 150–300 dpi 渲染读图取得；原文 PDF 未随本仓库发布）。
**对象**：EMISE/H₂O 与 [EMIM]DEP/H₂O 两工质对。EMISE = 1-乙基-3-甲基咪唑硫酸乙酯盐 [EMIM][EtSO₄]；[EMIM]DEP = 1-乙基-3-甲基咪唑磷酸二乙酯盐。全文组分编号：1 = 水，2 = 离子液体；x、x₂ 均为离子液体**摩尔分数**（Cp 式亦然，尽管 Cp 单位是 kJ/(kg·K)）。
**页码**：下文「论文 p.XX」为页脚印刷页码；PDF 页 = 论文页 + 9。
**核查方法**：除抄录方程与参数外，每套参数均用论文自家数据表的 exp/cal 值做了回代验算。判定分三级：**可提取**（方程+参数完整且验算通过）／**部分可提取**（缺项或印刷参数验算不符，注明补救路径）／**只有数据无公式**。

## 1. 蒸气压 —— NRTL 七参数模型（第 3 章，论文 p.26–35）

**模型形式（完整印出）**：IL 不挥发、气相纯水（y₁=1），γ₁ = P/(P₁^S·x₁)（式 3.4）；纯水饱和压用 Antoine 式（3.3）。NRTL 二元式（3.10）–（3.13），其中 τ₁₂ = a₁ + b₁/T + c₁·T、τ₂₁ = a₂ + b₂/T + c₂·T（式 3.17/3.18，由 Δg 的 T 二次式 3.16 导出），G_ij = exp(−α·τ_ij)。每体系 7 个可调参数（a₁,b₁,c₁,a₂,b₂,c₂,α），对 γ 的目标函数拟合（式 3.9）。

**纯水 Antoine 常数（表 3.3，论文 p.26，已抄录）**：log P^S/mmHg = A − B/(T/K + C)，A = 18.3036，B = 3816.4，C = −46.13。原文写作 "log"，验算确认实为自然对数（373.15 K → 760.0 mmHg）。

**NRTL 参数（表 3.6，论文 p.32，已抄录；行 i=1 → τ₁₂，i=2 → τ₂₁）**：

|---|---|---|---|---|---|---|
| H₂O(1)+EMISE(2) | 1 | −203.9746 | 77986.0607 | 0.0937 | 1.3306 | 2.16% |
| | 2 | 6.5592 | −2022.799 | 0.006 | | |
| H₂O(1)+[EMIM]DEP(2) | 1 | −154.334 | 22198.7564 | 0.2505 | 0.4017 | 2.07% |
| | 2 | 101.8665 | −20136.1594 | −0.137 | | |

**原始数据（完整印出，可作重拟合/校验集）**：表 3.4（EMISE，论文 p.29–30）：x₂ = 0.109/0.226/0.341/0.446/0.545，T = 312.20–373.35 K，共 45 点，含 P^exp、P^cal、γ₁^exp、γ₁^cal。表 3.5（DEP，论文 p.31–32）：x₂ = 0.0987/0.201/0.300/0.412/0.529，T = 339.05–411.05 K，共 40 点，列同上。

**回代验算结果（关键）**：
- **DEP 参数可用**：6 个抽查点中 4 点与印刷 γ^cal 偏差 +0.8%～−2.1%（行序对调则差 +22%～+264%，故映射无误）。两点例外：x₂=0.300 首点（T=345.95 K）模型 γ=0.175 vs 印刷 0.124（+41%）——该点 γ^exp=0.125 本身偏离本浓度块的平滑趋势，属拟合离群点（其对总 ARD 的贡献与作者自报 2.07% 相容）；x₂=0.529 首点（385.25 K）偏差 −9.3%，存疑但量级有限。
- **EMISE 参数不可用**：按印刷参数 τ₁₂≈+40～+62，G₁₂≈0，得 γ₁≈1.000–1.005，而印刷 γ^cal 为 0.266–0.557，全面不符；试过 α 变体、行序对调、Δg 诸式（3.14）–（3.16）的各种代入，均不能复现。判定为论文表 3.6 的 EMISE 参数行本身有误（与同表 DEP 行形式相同而量级异常）。**补救路径**：方程形式已经 DEP 验证无误，用表 3.4 的 45 点原始数据按式（3.17）/（3.18）七参数形式重拟合即可。

**附带说明**：作者另用拟合参数预测了 323.15 K 的 P/P^S 曲线（图 3.4，论文 p.34）——属外推演示，无数据表，不入程序。

## 2. 混合热 H^E —— Redlich–Kister，仅 298.15 K（第 4 章，论文 p.41–42）

**数据**：表 4.4（论文 p.41）只有 298.15 K 一个温度：EMISE 5 点（x₂ = 0.199–0.888），DEP 4 点（x₂ = 0.202–0.788），单位 kJ/kmol（= J/mol），全为负值（放热）。测量公式 Q = UIt、ΔH = Q/n（式 4.1/4.2）；装置以二甘醇+水体系校验（表 4.2，ARD 1.88%，文献 [64]）。

**关联式（完整印出，式 4.5）**：H^E = x₁(1−x₁)·Σ_{i=0..3} A_i (x₁−x₂)^i。
**参数（表 4.5，论文 p.42，已抄录；单位与数据同为 kJ/kmol）**：

| 体系 | A₀ | A₁ | A₂ | A₃ |
|---|---|---|---|---|
| EMISE+H₂O | −3668.584 | −3285.922 | −4019.051 | −148.0318 |
| [EMIM]DEP+H₂O | −23945.9 | −2527.43 | −3872.67 | −27487.2 |

**验算**：4 个抽查点复现印刷 H^E 值偏差 0.02%–0.96%，通过。作者未给该拟合的 ARD（仅图 4.4/4.5 与"吻合较好"）。
**缺口**：① 无温度依赖——H^E(T) 论文未给，焓–浓度组装时只能由 Cp 数据按 Kirchhoff 关系自行外推（论文未做）；② DEP 是 4 参数拟合 4 个数据点（零自由度），x 方向内插可信、外推不可靠；EMISE 为 5 点 4 参数。

## 4. 密度（第 5 章，论文 p.52–56）

- **EMISE 列不可用**：按印刷参数，x₂=1/303.55 K 得 ρ=2.951（印刷 cal 1.2649），x₂=0.201/303.25 K 得 1.2797（印刷 1.2167）。诊断：a 列自洽（Σa_i = 1.4574，与 cal 列纯组分截距所需 1.4575 吻合），b 列不自洽（Σb_i = +0.00492，所需 −0.00063）；单符号翻转、双符号翻转、指数移位均已扫描，无一能修复，错处无法由文本定位。**补救路径**：用表 5.2 数据按式（5.7）重拟合。作者自报 ARD 0.077%。

## 5. 黏度 —— Arrhenius-like 方程（第 5 章，论文 p.57–61）

**注意**：本论文用的不是 VTF，而是 Arrhenius-like 方程（式 5.8，出处 [72]）：
η = η_∞·exp(E_a/RT)，其中 E_a = Σ_{i=1..5} A_i·x^{i−1}（式 5.9），η_∞ = Σ_{i=1..5} B_i·x^{i−1}（式 5.10），x 为 IL 摩尔分数，η 单位 mPa·s，E_a 单位 J/mol（原文未标注，由量级与回代确认）。

**数据**：表 5.5（EMISE，论文 p.58–59）：x₂ = 0.201/0.411/0.581/0.787/1，T = 303.15–323.45 K，25 点，含 exp/cal；表 5.6（DEP，论文 p.59–60）：x₂ = 0.210/0.405/0.549/0.782/1，T = 298.05–323.25 K，30 点。相对法以二甘醇为标准液（校验 ARD 1.65%；其文献值实出自 [71]，表头误标 [68]）。

**参数（表 5.7、表 5.8，论文 p.61，已抄录）**：
A（E_a 多项式，J/mol）：EMISE：20838.97, 9594.59, 32763.58, −69661.11, 41684.30；DEP：26951.52, 37265.56, −25191, 25300.80, −23470.30。
B（η_∞ 多项式；表头标 B_i×10⁻²）：EMISE：0.1929, −1.0534, 3.0164, −3.5049, 1.3590；DEP：0.946, −4.5374, 9.5343, −9.8813, 4.1288。

**验算结果**：
- **EMISE 通过**：B 按表头 ×10⁻² 取值，抽查 8.900 vs cal 8.90（x₂=0.201）、54.92 vs 54.78（x₂=0.581）、114.6 vs 112.58（x₂=1，+1.8%，系 ΣB 为小差值、印刷位数不足所致）。作者 ARD 1.68%。
- **DEP 标度印刷有误**：B 按 ×10⁻² 取值时结果恰为印刷 cal 的 100 倍（27,557 vs 274.76）；按 **×10⁻⁴** 取值则 4 个抽查点全部复现（275.6/27.31/147.1/233.7 vs 274.76/27.22/146.23/231.44，偏差 ≤1%）。判定表 5.8 的 DEP 行（或表头指数）印刷差 100 倍，编程时 DEP 的 B 须用 ×10⁻⁴（推定修正，须注释标明）。作者 ARD 1.88%。

## 7. 适用范围红线（编程时必须写入边界）

- 蒸气压：EMISE x₂ 0.109–0.545 / 312–373 K；DEP x₂ 0.0987–0.529 / 339–411 K。泡点压 P = γ₁x₁P₁^S(T)，泡点温需求迭代。
- 密度、黏度、Cp 的多项式均只在实测浓度块内有效（x₂ ≳ 0.2 至 1），**不得向稀端外推**：如密度式（5.7）在 x→0 给出 1.16 g/cm³（水为 0.997）、Cp 式（4.6）在 x→0 给出 ≈3.23 kJ/(kg·K)（水为 4.18），均为拟合式在数据域外的假象。
- H^E 仅 298.15 K；密度/Cp/黏度温度域仅约 293–323 K，与蒸气压的高温域（至 411 K）不衔接——做全循环焓平衡时高温段的液体 Cp/ρ 只能外推使用，须在程序注释中声明。
