# NH₃–LiNO₃（氨–硝酸锂）溶液物性 — 公式说明

交付物：`nh3_lino3.py`（参考实现）、`nh3_lino3.c`、`nh3_lino3.bas`（Excel VBA 工作表函数），及三张泡点–露点差曲线图。

## 来源

全部关联式转录自 Amaris Castilla, C.F. (2014) 博士论文《Intensification of NH3 Bubble Absorption Process Using Advanced Surfaces and Carbon Nanotubes for NH3/LiNO3 Absorption Chillers》（Universitat Rovira i Virgili）**附录 B（pp. A-6～A-8）**，2026-10-03 用 pdftotext 重新提取并逐项复核。原始文献：

| 物性 | 原始来源 | 形式 |
|---|---|---|
| 泡点压力 | Libotean et al. (2007), J. Chem. Eng. Data 52, 1050–1055 | ln P = pa(x) + pb(x)/T |
| 液体焓 | Vallès & Salavera (2011, CREVER 内部报告), Haltenberger (1939) 法 | H = ha(x) + hb(x)·T + hc(x)·T² |
| 比热 | Libotean et al. (2008) | Cp = cpa(x) + cpb(x)·T |
| 密度 | Libotean et al. (2008) | ρ = 1000·(da(x) + db(x)·T) |
| 导热 | Cuenca et al. (2013a) | k = ka1 + ka2·T + ka3·T² + ka4·x |
| 结晶界限 | Infante Ferreira et al. (1984) | XCRIS 十分段多项式（原文伪代码） |
| 黏度 | Libotean et al. (2008), JC&ED 53, 2383–2388 | **未入库**，见下 |

## 约定

- **x = 氨质量分数（小数，如 0.5）**，全部关联式皆然；
- T 为 K；压力 kPa；焓 kJ/kg；比热 kJ/(kg·K)（原文 J/(g·K)，数值相同）；密度 kg/m³；导热 W/(m·K)；
- 结晶函数 `x_cris(T_C, x)` 的 T 用 **°C**（与原文伪代码一致）。

范围外行为：Python raise ValueError；C 返回 NAN；VBA 返回 #VALUE!。不静默外推。

## 参考态（焓）

**保留来源原文参考态**：氨的焓以 0 °C 时 0 kJ/kg 为零点；混合物参考态为 **0 °C、氨质量分数 0.5 时 H = 0 kJ/kg**。验算：`h_liq(273.15, 0.5) = 0.0024 kJ/kg ≈ 0` ✓。

⚠️ 此参考态与本库其他工质对（如 R22–DMF、氨水的 273.15 K 饱和液体 = 100 kJ/kg 约定）**不同**，跨工质对比较焓值前必须先对齐参考态；同一工质对内作焓差不受影响。

## 结晶界限的实现说明

论文附录 B 的伪代码为 `XCRIS = f(TSol[°C], xSol)`：**以溶液氨质量分数 xSol 选择分支**，每段是 T[°C] 的多项式。因此函数签名须同时带 T 与 x（`x_cris(T_C, x)` / `NL_Xcris(T_C, x)`），无法只用温度一个自变量。实现要点：

- 十分段逐字转录，无缺段；
- 原文分支为严格不等式，端点（如 x = 0.2911）无定义；实现时端点归入以其为下限的相邻段；
- 第 2 段（0.2911 < x < 0.3）原文即 `XCRIS = X`，照录；
- 个别段的返回值可大于 1（如 x = 0.85、25 °C 时 XCRIS ≈ 8.57），说明 XCRIS 并非全域都是质量分数——其物理量纲与判定用法以 Infante Ferreira et al. (1984) 原始报告为准，本模块只作忠实转录，不作过度解读。

## 导热 ka3 项的歧义

论文附录 B 印作 `k = ka1 + ka2·T + ka3·T²·x + ka4·x`（ka3 项带 x）。本实现按**不带额外 x** 的读法：`k = ka1 + ka2·T + ka3·T² + ka4·x`。两读法在 300 K、x = 0.4 处分别为 0.360 与 0.348 W/(m·K)，差约 **3%**。若日后核对 Cuenca et al. (2013a) 原文确认带 x，三种语言各改一处即可。

## 黏度为何不入库

论文附录 B 的黏度式排版残损：原式呈 `μ = e^(1000·va / vb / T)` 的堆叠形式，算符在印刷中丢失，无法确证。按数值合理性的重构式

μ = exp(va·1000/T + vb)，va = 1.918 + 10.094x − 18.394x²，vb = −1.205 − 35.627x + 51.529x²

抽检量级合理（x = 0.45：313.15 K → 6.9 mPa·s，293.15 K → 12.5 mPa·s），但**未经原文核实**，故仅在 Python 中以 `mu_visc` 提供并标记 EXPERIMENTAL/UNVERIFIED，C 与 VBA 不实现。对照核实源：Libotean et al. (2008), J. Chem. Eng. Data 53, 2383–2388。

## 泡点–露点差曲线（三张图）

LiNO₃ 不挥发，气相视为纯氨，**露点取纯氨饱和温度**（由本库氨水模块 Pátek–Klomfar 关联式在摩尔分数 = 1 处求得）：

ΔT(p, x) = T_bubble(p, x) − T_sat,NH3(p)（符号为正）

图只画在关联式有效域内（泡点温度 293.15–353.15 K、x 0.35–0.65），之外截断不外推。抽查：6 bar、x = 0.5 时 ΔT = 36.3 K；2 bar、x = 0.40 时 ΔT = 60.2 K。
