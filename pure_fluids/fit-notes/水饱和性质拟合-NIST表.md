# 水 Water (H2O)：饱和性质紧凑拟合（源：NIST WebBook 饱和表）

- 源表：Saturation_Properties_for_Water___Temperature_Increments.xlsx（页 'Saturation Properties for Water'），共 373 个温度点，1…373 ℃（步长约 1 ℃），液/汽两相全物性列；本拟合只取饱和压、饱和液焓、饱和汽焓三列。
- 临界常数（Wagner 式用）：Tc=647.096 K、Pc=22.064 MPa（IAPWS 公认临界值）。
- 变量与单位：t 为 ℃，T 为 K，压力 MPa，焓 kJ/kg。辖区：仅在表范围 1…373 ℃ 内使用，不外推。常用带取 5…300 ℃，残差与全程分开列。
- 焓参考态为 NIST WebBook 自带参考态（与 IAPWS 惯例一致）。
- **定位声明**：水的权威标准是 IAPWS 公式（IF95/IF97），本拟合只是一个可移植的紧凑多项式式（便于 Excel/VBA/C 随表使用），不替代 IAPWS；残差如实列于下文，凡正式计算以 IAPWS/CoolProp 为准。

## 一、饱和压

试了两种式形（残差均为拟合值对表值的相对偏差）：

1. **Wagner 型** ln(P/Pc)＝(Tc/T)·[a·τ＋b·τ^1.5＋c·τ^3＋d·τ^6]，τ＝1−T/Tc：a＝-7.78125078，b＝1.48515014，c＝-2.78728572，d＝-1.28490204。全程最大 0.0645%、RMS 0.0279%；常用带最大 0.0378%、RMS 0.0228%；全程单调＝True。
2. **lnP–t 多项式（7 次）** ln(P/MPa)＝Σc_k·t^k：全程最大 0.0291%、RMS 0.0060%；常用带最大 0.0128%、RMS 0.0054%；全程单调＝True。（6 次式全程最大 0.1798%、RMS 0.0423%，供对照。）

## 四、VBA 函数文本

**注意：以下 VBA 未在真实 Excel 中测试**，使用前请先在 Excel 里对表值抽查 2–3 个点。输入 tC 为 ℃；Psat 返回 MPa；HLiq/HVap 返回 kJ/kg（表参考态）；只在辖区内使用，函数内不设外推护栏。

```vb
Function H2O_Psat(ByVal tC As Double) As Double
    Dim t As Double: t = tC
    Dim lnP As Double
    lnP = (-7.399704960820133) + (0.07259423527358563) * t + (-0.0002954387998568004) * t ^ 2 + (1.056735995405781e-06) * t ^ 3 + (-3.088083641876246e-09) * t ^ 4 + (6.660700555390007e-12) * t ^ 5 + (-8.99249875691861e-15) * t ^ 6 + (5.54627791673895e-18) * t ^ 7
    H2O_Psat = Exp(lnP)
End Function

Function H2O_HLiq(ByVal tC As Double) As Double
    Dim t As Double: t = tC
    H2O_HLiq = (6.648110281391315) + (3.3541747407753046) * t + (0.02553352332697852) * t ^ 2 + (-0.0003141174119157094) * t ^ 3 + (1.8115766448129802e-06) * t ^ 4 + (-4.8364685293173926e-09) * t ^ 5 + (4.9253814056437e-12) * t ^ 6
End Function

Function H2O_HVap(ByVal tC As Double) As Double

End Function
```
