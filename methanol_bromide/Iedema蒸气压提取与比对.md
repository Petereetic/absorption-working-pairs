## 1. 提取的公式（表 2.6.4.2，论文 p.97 / PDF p.119，300 dpi 读图逐字核对）

针对三元混合盐的简化关联式（作者由其状态方程计算结果拟合而来，论文 p.96 明文）：

```
ln{ p0(T) / p(w,T) } = a(w)/T + b(w)          (p 以 mbar 计，T 以 K 计)
p0(T) = p1 + p2/T + p3/T^2
a(w)  = a1 + a2·w + a3·w^2 + a4·w^3 + a5·w^4
b(w)  = b1 + b2·w + b3·w^2 + b4·w^3 + b5·w^4
```

| 系数 | 值 | 系数 | 值 | 系数 | 值 |
|---|---|---|---|---|---|
| p1 | 1.874037×10¹ | a1 | −1.959784×10⁵ | b1 | 5.416153×10² |
| p2 | −3.498560×10³ | a2 | 1.989094×10⁶ | b2 | −5.414318×10³ |
| p3 | −1.663928×10⁵ | a3 | −7.373894×10⁶ | b3 | 1.996754×10⁴ |
|  |  | a4 | 1.194267×10⁷ | b4 | −3.231367×10⁴ |
|  |  | a5 | −7.162617×10⁶ | b5 | 1.940737×10⁴ |

**印刷约定（数值裁定）**：p0(T) 按印刷式算出的数值等于纯甲醇蒸气压（mbar）的自然对数，而非压力本身：exp(p0) 在 0/25/40/64.7/100/120 °C 为 40.5/169.7/354.8/1019.7/3532/6407 mbar，与纯甲醇蒸气压真值（40/170/354/1013/3536/6387 mbar 量级）吻合至 ±5% 以内。故实现为 ln p(w,T) = p0(T) − a(w)/T − b(w)（mbar），再换算 bar。w 为甲醇质量分数（与表 2.4.2、图 2.6.4.2c 的标注一致）。

适用范围（原表）：**w = 0.30–0.45，t = −20–140 °C**。

## 2. 混合盐比例：原文依据（本论文的悬案就此关闭）

- §2.4.1（论文 p.65）：所发表数据为 "vapour pressures of LiBr/ZnBr₂/CH₃OH **(2 : 1)**"，稀释/溶解热、密度、黏度同为该三元 (2:1) 体系；
- §2.4.2（论文 p.65）："The measurements were carried out with LiBr/ZnBr₂/CH₃OH (2 : 1)"，试剂为工业纯（LiBr 99.2%，ZnBr₂ 98%），样品含水 0.7%；
- 附录 1（论文 p.297–299）以参数 y 定义混合盐（1 mol 混合盐 = y mol LiBr + (1−y) mol ZnBr₂，ν = 3−y），2:1 即 y = 2/3。

**结论：Iedema 的混合盐就是 LiBr∶ZnBr₂ = 2∶1 摩尔比，与 El-Shamarka 完全相同。** 本关联式直接以质量分数 w 给出，无 molality 换算问题。

## 3. 精度链（作者自述）

1. 测量：Utrecht 大学静态法，温度精度 0.01 K，**压力精度估计 2%**（§2.4.2）；
2. 状态方程（表 2.6.3，64 个 b_ij）对自家 44 点实测的蒸气压平均相对偏差 Δ̄r（表 2.6.2.1，论文 p.76）：w=0.2849 组 5.0%、0.3050 组 2.6%、0.3458 组 3.4%、0.4035 组 2.3%（渗透系数口径同批数据为 1.0%）；
