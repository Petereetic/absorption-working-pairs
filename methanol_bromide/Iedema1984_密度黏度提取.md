# Iedema 1984 密度与黏度关联式（2026-10-03 提取验证）

来源：P. D. Iedema 博士论文《The Absorption Heat Pump with Lithium Bromide/Zinc Bromide/Methanol》，TU Delft，1984。第 2.7 节（PDF p.127–128，论文 p.105–106）。
文件：作者藏本扫描件（原文 PDF 未随本仓库发布）

变量：w_t = 总溶剂质量分数（CH₃OH + H₂O），w_H = 水质量分数，t 为 °C，T 为 K。
混合盐比例已确认：§2.4.1、§2.4.2（论文 p.65）明文 LiBr/ZnBr₂/CH₃OH (2 : 1) 摩尔比，与 El-Shamarka 相同（2026-10-03，见《Iedema蒸气压提取与比对.md》）。"technical purity grade" 出自 §2.4.2 试剂说明。

## 密度（表 2.7.2.2.2，作者称平均偏差 0.13%）

ρ(t, w_t, 0) = ρ(25, w_t, 0) + ρ′(w_t)·(t − 25)    [ρ: kg/m³]
ρ(25, w_t, 0) = ρ1 + ρ2·w_t + ρ3·w_t² + ρ4·w_t³
ρ′(w_t)       = d1 + d2·w_t + d3·w_t² + d4·w_t³
含水修正 (A.5.1)：ρ(t, w_t, w_H) = ρ(t, w_t, 0)·(1 + H·w_H)，H = 0.32

ρ1 = 3.026745e3   ρ2 = −5.369240e3   ρ3 = 4.082056e3   ρ4 = 1.038639e2
d1 = −9.975370e−2  d2 = −1.177377e1   d3 = 4.224796e1   d4 = −4.470839e1

适用：w_t = 0.28–0.42，t = −10–140°C。
验算：ρ(0.3483, 19.5°C) = 1661.5 vs 实测 1664.5（−0.18%）✓

## 黏度（表 2.7.3，作者自测数据平均偏差 2.8%）

ln η(T, w_t) = η0(w_t) + ηT(w_t)/T    [η: Pa·s]
η0 = −18.29756 + 26.23730·w_t − 33.51444·w_t² + 13.86405·w_t³
ηT = 5481.757 − 11371.61·w_t + 10873.40·w_t² − 3718.145·w_t³

适用：w_t = 0.28–1.0，t = 20–120°C（关联含 Uemura 数据，权重 1，偏差 8.2%）。

**印刷问题裁决（2026-10-03 数值验证）**：原表 ηT 公式末项印作 w_t⁴、系数下标有重复错标（两个 η_T2）。按 w³ 读法对 9 个实测点偏差 −4.0%~+5.1%、平均绝对值 **2.8%**，与作者自称完全吻合；按 w⁴ 读法平均偏 36%，证伪。故取 w³、系数依次为 η_T1..η_T4。

验算点（Pa·s）：(0.3916, 20°C) 算 0.0204 vs 测 0.0212；(0.2919, 20°C) 算 0.0535 vs 测 0.0524。

## 与 El-Shamarka 的交叉核对（2026-10-03）

El-Shamarka 表 4.2 硬实测点 w=0.253、50°C → 约 1914 kg/m³：
- El-Shamarka 式(4.10) 印刷版（0.0068）：1611（−16%，已知误印）
- El-Shamarka 修正版（0.00068）：1917（+0.2%）
- **Iedema 式（w_t=0.253 已属范围外外推）：1904（−0.5%）** —— 两独立来源互证，且支持"同一混合物"

但在 w=0.30–0.35 两式差 2.5–3.1%（Iedema 偏低）：El-Shamarka 线性式只靠单点修正过小数点、本身可能粗糙，仲裁需其表 4.2 原始数据（尚未数字化）；Iedema §2.3.2 实为纯甲醇节，混合物制备/盐比定义仍未定位到原文，数值证据暂时偏向同一混合物。
