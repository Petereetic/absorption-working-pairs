# R124-NMP 工质对公式说明

**来源**：Xu Shiming, Wang Wei, Wu Xi, Hu Jungyong, Jiang Mengnan,
"Measurement and Correlation of Vapor-Liquid Equilibrium for
R124-NMP and R124-DMF Mixtures", *Journal of Chemical & Engineering
Data* 2017, 62, 3414–3422. DOI: 10.1021/acs.jced.7b00444
（大连理工大学海洋能源利用与节能教育部重点实验室）

## 模型（原文式 4–11）

五参数 NRTL 活度系数（组分 1 = R124，组分 2 = NMP）：

    tau12 = (a1 + b1 ln T) / (RT),   tau21 = (a2 + b2 ln T) / (RT)
    G12 = exp(-alpha * tau12),       G21 = exp(-alpha * tau21)
    ln gamma1 = x2^2 [ tau21 (G21/(x1+x2 G21))^2 + tau12 G12/(x2+x1 G12)^2 ]

泡点压力（gamma-phi，蒸气视为纯 R124，含 Poynting 修正，隐式迭代）：

    p = ps1 * x1 * gamma1 * exp( VL1 (p - ps1) / (RT) )

参数（原文表 8，能量单位 J/mol）：

    a1 = 242408    b1 = -46295.3
    a2 = -166747    b2 = 30875.3
    alpha12 = -0.0515   （负值系原文印值，已由实测数据复算证实无误）

纯 R124 饱和压 ps1 与饱和液摩尔体积 VL1：对原文表 5 的 REFPROP 值
（303.15–363.15 K 共 7 点）作拟合：

    ln(ps1/kPa) = 14.750463 - 2527.6371 / (T/K - 10.9815)   最大偏差 0.05%
    VL1 = (3.43888821e-06 Tc^2 + 5.21631071e-06 Tc + 9.89804979e-02) / 1000
          [m3/mol，Tc 为 degC]                                最大偏差 0.24%

注：若纯组分蒸气压改用 Borde 1997 式 (15)（见 r124_dmac），其值在
303 K 比 REFPROP 低约 2.3%，本模型对实测的 AARD 将由 1.25% 升至
约 2.3%——本对的蒸气压锚点以 REFPROP 为准。

## 约定与辖区

- 浓度变量 xi = R124 质量分数；M(R124) = 136.50，M(NMP) = 99.13 g/mol。
- 温度 degC、压力 MPa（公开边界，2026-10-14 改定；内部原生单位仍为 bar，系数与公式逐字不动，公开函数只在边界缩放：返回压力 MPa = bar × 0.1、入参压力 MPa × 10 回 bar）。
- **适用范围 T = 30–90 degC**（原文实测的 303.15–363.15 K），函数在
  范围外 Python 返 None、C 返 NAN、VBA 返 Empty，不外推。
- 吸收剂视为不挥发（原文实验结论：气相中 NMP 可忽略），露点取纯
  R124 饱和温度。露点是纯流体参考线：30 °C 以下 Antoine 式作短程
  外推（下限 −30 °C），不属于混合物模型的拟合辖区。
- **未覆盖**：混合物焓、密度、黏度——原文无此数据，本库不编造。

## 函数清单

| 函数（C/VBA 名；Python 名） | 说明 |
|---|---|
| `Pref_R124NMP(T_C)`（`pref_R124`）/ `TsatR124(P_MPa)`（`Tsat_R124`） | 纯 R124 饱和压力（MPa）/ 饱和温度（°C），Antoine 式 |
| `Psol_R124NMP(T_C, xi)`（`psol`） | 泡点压力，MPa（ξ = R124 质量分数） |
| `BubbleT_R124NMP(P_MPa, xi)`（`bubble_T`） | 二分反解泡点温度，°C（无根返回 None / NAN / Empty） |
| `DewT_R124NMP(P_MPa)`（`dew_T`） | 露点温度（纯 R124 饱和温度），°C |
| `XiByTsolTdew_R124NMP(Tdew_C, Tsol_C)`（`xi_by_tsol_tdew`） | 由露点温度与溶液温度反解浓度 ξ（质量分数）：露点定压 P=PsatR124(Tdew)，再二分求 BubbleP(Tsol, ξ)=P；括号取泡点函数有效浓度域 (0, 1) 的两端极限（ξ→0 时 P→0、ξ→1 时 P→PsatR124(Tsol)），二分只取内点；无根（如溶液温度低于露点温度，或 Tsol 在 30–90 °C 之外）返回 None / NAN / Empty。2026-10-11 增补，C/Python 双验：(20, 90)→0.50162、(20, 60)→0.69015、(10, 50)→0.67387，往返误差 ≤4.5×10⁻¹⁶ |

## JavaScript 套（2026-10-23 新增）

- `r124_nmp.js` — 本模块的 JavaScript 实现，函数名与 Python 版逐一同名、无别名；ξ 为 R124 质量分数、T 为 °C、压力公开边界 MPa（模型内部保留 bar，只在边界换算），口径与本说明一致。共 10 函数：pref_R124、Tsat_R124、xi_to_x、x_to_xi、gamma1、psol、bubble_T、xi_by_tsol_tdew、dew_T、tdew_by_tsol_xi。
- 辖区纪律：明写辖区外抛 RANGE 错误（pref_R124 与 gamma1、psol 的 T∈[30, 90] °C、分数换算的定义域 [0, 1]、psol 与 bubble_T 的 ξ 定义域）；内部调用一律走 raw 私有版，公开检查不拦内部求值（xi_by_tsol_tdew 以 raw 版求 Pref(Tdew)，Tdew 可在 30 °C 以下）。Python 返 None 处返 null（psol 与 gamma1 的 ξ 端点、bubble_T 超跨度、xi_by_tsol_tdew 无根、dew_T 露点窗 −30…90 °C 外、tdew_by_tsol_xi 同窗外、Tsat_R124 的 P≤0）。设计性分账：pref_R124 与 gamma1 在 T 带外、xi_by_tsol_tdew 在 Tsol 带外时 JS 抛 RANGE，Python 同点或返数值（pref 无检查）或返 None。迭代逐字镜像 Python（psol 的 Poynting 隐式迭代 50 次、bubble_T 二分 60 次、xi_by_tsol_tdew 二分 80 次）。
- 负记录两处：①xi_by_tsol_tdew 在 Tsol＝Tdew 时根恰在 ξ＝1 端点，Python 参考版自身会因二分中点取到 1.0 后 `_psol_bar` 返 None 而抛 TypeError（(50,50)/(60,60)/(90,90) 实测皆然）——该点 Python 侧无值/null 分类，JS 同算法下返 1；②bubble_T 括号上沿边点 bubble_T(psol(90 °C, 0.5), 0.5)：Python 经公开 MPa 往返（×0.1 再 ×10）对自身上沿高 1 ulp 而返 None（xi=0.1/0.3/0.5 同样、0.7/0.9/0.99 返 ≈90，Python 自身不自洽），JS 返数学上正确的根 89.99999999999991——此现象已见全库 MPa 改造盘点 §7.1 的末位舍入注记（×0.1 再 ×10 双精度不恒等）。两处均已登记在验算报告中，未为迁就改算法。
- 对数验证：与 Python 参考版逐点比对网格 923 点（值点 763、null 点 160），值点超差（相对差 >1e-9）零，最大相对差 4.53×10⁻¹⁴（tdew_by_tsol_xi）；分类仅上条负记录 ② 一处 1-ulp 边点分账，余零不符；另加随机网格 1,598 点（种子 20261023）分类零不符、最大相对差 3.35×10⁻¹⁴；RANGE 清单 24/24 全过。锚点复现：Pref(30/60/90 °C)＝0.4454851153785402/0.9970131232231746/1.9451833778933183 MPa、Psol(60 °C, 0.5)＝0.1535816323288159 MPa、DewT(0.1535816 MPa)＝−2.022656855 °C；XiByTsolTdew 三锚 (90,20)→0.5016205446707862、(60,20)→0.6901509946072946、(50,10)→0.6738676247563287。
- 已上线 peterinno.com 试算页（API 路由 /api/calc/r124-nmp，视图六框：(T, ξ) 族、(T) 纯 R124、(P, ξ) 反解、xi_by_tsol_tdew、xi_to_x、x_to_xi；全 10 函数在 API 目录中）。

> **VBA 函数命名（2026-10-12 改定）**：VBA 公开函数名一律为「属性_工质对」形（如 `Psol_R124NMP`），因 Excel 工作表公式不接受以 R+数字打头的函数名（R1C1 引用形状，用户实测）。C 版函数名保持 `R124NMP_*` 原形、Python 版为小写蛇形，三者同算法同数值。由露点与溶液温度求浓度的函数 VBA 名为 `XiByTsolTdew_R124NMP`。

## 2026-10-12 全库命名统一与新增函数

本节记录 2026-10-12 的全库统一命名与两个新增必备函数。旧名不留别名、彻底退场。

**命名分账**：`Psol` = 溶液表面（平衡）蒸气压（原泡点压力函数），`Pref` = 纯制冷剂饱和压力，两者分账、不可互换。纯制冷剂饱和液焓为 `hliq`、饱和气焓为 `hgas`、潜热 `hlat = hgas - hliq`（两焓同基准才可减）；溶液焓为 `hsol`，与纯制冷剂的 hliq 分账。

### 新增：TdewByTsolXi（由溶液温度与浓度求露点温度）

定义（全库统一）：`TdewByTsolXi(Tsol, xi) = 模块 Tsat(Psol(Tsol, xi))`；本模块即与已有 DewT 复合：`dew_T(psol(T_C, xi))`（纯 R124 线为模块内 Antoine 式）。Python `tdew_by_tsol_xi`、C `R124NMP_TdewByTsolXi`、VBA `TdewByTsolXi_R124NMP`。单位 °C，xi 为 R124 质量分数，P 为 MPa（公开边界）。NMP 视为不挥发。无解约定随 psol/dew_T：Python 返 None、C 返 NAN、VBA 返 Empty。纯端锚：xi = 0.999、T = 60 °C 时 Python 版 Tdew = 59.94 °C（偏差 −0.06 K，同左）。

**已修复（2026-10-12）**：C 与 VBA 版 `TsatR124` 曾有符号错误——Antoine 常数 C = −10.9815，反解饱和温度应取 +10.9815，两版误写为 −，使 C/VBA 的 DewT 与 TdewByTsolXi 恒偏低 21.963 K（Python 版一直正确；XiByTsolTdew 不经 TsatR124，不受影响）。两版已改对，复验：gcc 编译后 C 版 TdewByTsolXi(60 °C, 0.50) = −2.022651 °C（修复前 −23.985651），与 Python 逐位一致；DewT(0.1535816 MPa) = −2.022656855 °C 亦与 Python 逐位一致（原锚 DewT(1.535816 bar)，2026-10-14 单位改定后换算注记，数值不变）。同批一致性修正：Python 版无根/越界返回值由 NaN 统一为 None（与全库其余八对一致），verify 脚本复跑通过（AARD 1.25% 不变）。VBA 未在真实 Excel 中编译。

## 2026-10-14 压力单位改 MPa

三套（Python/C/VBA）公开压力边界由 bar 改为 MPa：返回压力 MPa = bar × 0.1，入参压力 MPa × 10 回 bar 进内部。系数与公式逐字不动；现行函数体改为私有原生（bar）函数，公开函数只做边界缩放，内部调用改走私有原生函数，故温度/浓度输出逐位不变。函数名不改；参数名 `P_bar` 改为 `P_MPa`（私有原生函数仍用 `P_bar`）。`verify_r124_nmp.py` 同步换算（MPa → kPa × 1000），复跑 AARD 1.25% 不变。VBA 版未经真实 Excel 编译/实测。
