# R22-DEGDME 热力学关联式说明

来源：E. Ando, I. Takeshita, "Residential gas-fired absorption heat pump based on
R22-DEGDME pair. Part I Thermodynamic properties of the R22-DEGDME pair",
*Int. J. Refrigeration*, Vol.7, No.3, pp.181–186, 1984.
（用户硬盘存档：`~/workspace/user/files/Residential_gas-fired_absorption_heat_pump_based_on_R22-DEGDME_pair.pdf`）

注意：这是 **R22-DEGDME**（二乙二醇二甲醚），不是 R22-DMF，不能直接验证
R22-DMF 的 Fatouh 1993 焓模型。同属 R22+有机吸收剂家族，方法论可参照。

## 关联式（全部可算，常数取自论文表2、表3及式(7)）

**式(1) 泡点压力（Rankine 方程）**
lnP = Σₙ₌₀⁵ AₙXⁿ + (1/T)·Σₙ₌₀⁵ BₙXⁿ + lnT·Σₙ₌₀⁵ CₙXⁿ
- P: kg/cm²；T: K；X: R22 摩尔分数（源式原生单位，待裁保留）
- 适用：X=0.1~1.0，P=0.1~30 kg/cm²，T=−20~190°C；151 点，平均相对偏差 0.79%

**式(6) 摩尔热容**
C = Σₙ₌₀³ AₙXⁿ + t·Σₙ₌₀³ BₙXⁿ + t²·Σₙ₌₀³ CₙXⁿ
- C: J/mol/°C；t: °C；全浓度，t=−30~110°C；193 点，平均相对偏差 0.83%

**式(7) 混合热（10°C 下测定，11 点，平均相对偏差 0.72%）**
ΔHm = X(1−X)·Σᵢ₌₁⁴ Gᵢ(1−2X)ⁱ⁻¹，J/mol，放热为负
- G₁=−19061, G₂=8728, G₃=−1394.8, G₄=−642.18
- X=0.5 时 ΔHm=−4765 J/mol，与论文图 6 最低点（约 −5000）吻合

**式(9) 溶液焓组装**
H(T,X) = (1−X)H₁ + X·H₂ + ΔHm + ∫(Tm→T) Cp dτ

## 参考态（本文档约定，论文 Part I 未固定绝对焓值）
- 纯组分液体在 Tm=10°C 时焓为 0
- H(T,X) = ΔHm(X) + ∫(10°C→t) Cp(X,τ)dτ  [J/mol]，除以混合物摩尔质量换算为 kJ/kg
- 摩尔质量：R22 86.47 g/mol，DEGDME 134.17 g/mol

## 验算
- X=1、10°C：P=7.513 kg/cm²（R22 饱和压力实际约 6.9；混合物关联式外推纯组分，量级正确）
- X=0.5、10°C：P=0.1185 MPa；80°C：P=0.9057 MPa（psol_bar 导出线，2026-10-14 由 bar 改 MPa，见文末改定节）
- C 版（gcc -O2 -Wall 零警告）与 Python 版 36 点网格逐点比对，最大偏差 4.9×10⁻⁷
- VBA 版（r22_degdme.bas）常数与 C/Python 逐项核对一致，**未在真实 Excel 中编译运行**

## 2026-10-12 全库命名统一与新增函数

本节记录 2026-10-12 的全库统一命名与两个新增必备函数。旧名不留别名、彻底退场。

**命名分账**：`Psol` = 溶液表面（平衡）蒸气压（原泡点压力函数），`Pref` = 纯制冷剂饱和压力，两者分账、不可互换。纯制冷剂饱和液焓为 `hliq`、饱和气焓为 `hgas`、潜热 `hlat = hgas - hliq`（两焓同基准才可减）；溶液焓为 `hsol`，与纯制冷剂的 hliq 分账。

### 新增：TdewByTsolXi（由溶液温度与浓度求露点温度）

定义（全库统一）：`TdewByTsolXi(Tsol, xi) = 模块 Tsat(Psol(Tsol, xi))`。本模块纯 R22 线没有独立函数，就是式 (1) 在 X=1 的端点，故 Tdew 为满足 `psol_kgcm2(1.0, Tdew+273.15) = psol_kgcm2(X, t_C+273.15)` 的温度，二分 80 次反解。Python `tdew_by_tsol_xi(X, t_C)`、C `r22degdme_TdewByTsolXi`、VBA `TdewByTsolXi_R22DEGDME`（本模块函数惯例为 (X, T) 参数序，从之）。单位：Tdew、t_C 为 °C（kg/cm² 版为 K），X 为 R22 摩尔分数，P 内部为 kg/cm² 原生值（公开导出线 `psol_bar` 返回 MPa、函数名原名保留待裁，另有 kg/cm² 版 `psol_kgcm2`）；内部衔接一律走原生 kg/cm² 函数、不经 MPa 导出线，温度输出逐位不变。求解括号 t ∈ [−50, 190] °C：注意式 (1) 标称温度辖区为 −20~190 °C——溶液的露点温度常低于 −20 °C（如 X=0.3、t=60 °C 时 Tdew = −21.21 °C），该段结果用到纯端在标称辖区之外的外推（Rankine 型方程形式外推），引用时须连同此标注。DEGDME 视为不挥发。无解（P 超出括号内纯端压力跨度）时：Python 返 None、C 返 NAN、VBA 返 Empty。纯端锚：X=1 时 Tdew 与 t 精确相等（构造）。

### 新增：TsolByHsol（hsol 的反函数）

`TsolByHsol(h, X)` 满足 `hsol(X, TsolByHsol(h, X)) = h`：对 hsol 在求解括号 t ∈ [−30, 110] °C（式 (6) 辖区）内二分 100 次（hsol 在固定 X 下随 t 单调增）。Python `tsol_by_hsol`、C `r22degdme_TsolByHsol`、VBA `TsolByHsol_R22DEGDME`。h 超值域时：Python 返 None、C 返 NAN、VBA 返 Empty。验算往返误差 < 1e-6 K 量级。

## 2026-10-14 压力单位改定：bar 导出线改 MPa

- **改动范围仅一条公开压力边界**：`psol_bar`（Python）/ `r22degdme_psol_bar`（C）/ `Psol_R22DEGDME`（VBA，原 bar 线）。**函数名一律原名保留（改名待裁），返回值单位已由 bar 改为 MPa**：MPa 值 ＝ 式 (1) 原生 kg/cm² 值 ×0.0980665（精确定义 1 kg/cm² = 0.0980665 MPa；原 bar 线为 ×0.980665）。
- **锚值**：X=0.5、10 °C：0.1185 MPa（原 1.185 bar）；X=0.5、80 °C：0.9057 MPa（原 9.057 bar）。
- **内部衔接改走原生**：`xi_by_tsol_tdew` 与 `tdew_by_tsol_xi`（三套同）内部改用 `psol_kgcm2` 原生 kg/cm² 函数衔接，不再经导出线，温度/浓度输出逐位不变（复验见当轮回执）。
- **kg/cm² 变体线原样不动（待裁保留）**：`psol_kgcm2` 及其原生内部函数逐字未动；式 (1) 源式引文的 kg/cm² 口径原样保留（上文已加注「待裁保留」）。上表改名清单中的 `psol_bar` 等为函数名的历史记录，非单位标注。
