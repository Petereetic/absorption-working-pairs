# R124–DMAC 工质对模型说明

吸收式制冷/热泵工质对：制冷剂 **R124**（2-氯-1,1,1,2-四氟乙烷，CHClFCF₃），
吸收剂 **DMAC**（N,N-二甲基乙酰胺，C₄H₉NO）。Borde 等的综合评价
（COP、循环比 f、热稳定性）中 R124–DMAC 为五种候选吸收剂
（DMAC、NMP、DMEU、MCL、DMETEG）中的最优组合。

## 出处

I. Borde, M. Jelinek, N. C. Daltrophe, “Working fluids for an absorption system
based on R124 (2-chloro-1,1,2,-tetrafluoroethane) and organic absorbents”,
*Int. J. Refrigeration* 20(4), 256–266, 1997。PII: S0140-7007(97)00009-01。

全部系数自该文逐表转录（300 dpi 放大复核）。一份引用该文的大连理工大学
硕士论文篡改了其中两张系数表——核验与排除记录见
`Borde1997与硕士论文_核验.md`；本模型不采用该论文的任何数字。

## 约定

- ξ = 溶液中 R124 的**质量分数**；x = R124 的**摩尔分数**
  （M_R124 = 136.50，M_DMAC = 87.12 g/mol，原文表 1）。
- T 为开尔文（注明 t 时为 °C）；P 为 bar；h 为 kJ/kg；ρ 为 kg/m³；η 为 mPa·s（= cP）。
- 焓参考态：两纯组分液体在 0 °C 时 h = 100 kJ/kg（原文约定）。

## 模型方程（编号为原文式号）

**(15) 纯组分蒸气压**（原文表 2 给出全部六种组分系数；表 2 题注误标为
“Equation (1)”）：
ln(Ps/bar) = A + B/(T+C) + D·T + E·ln T + F·T²。
验算：六组分在各自正常沸点（表 1）处给出 0.97–1.02 bar（目标 1.013）。

**(16) 泡点压力**（系数表 3，64 个 p_ij，SPSS 逐步回归）：
P = Σ_{j=0..7} Σ_{i=0..7} p_ij ξⁱ Tʲ。
**辖区**：0–140 °C、ξ ≤ 0.95。该式在 ξ=1 端比式 (15) 系统性偏高 +13%～+23%
（原文拟合特性，见核验记录 §4.1），ξ→1 时应改用 Pref（纯 R124 线；2026-10-12
前即式 (15)，现为 NIST 拟合，见下文换源记录）；ξ=0 端绝对偏差
≤ 0.028 bar。实验装置上限 150 °C / 20 bar。

**(19) 比超额焓**（系数表 4；由 UNIFAC 模型生成的点回归，非直接量热数据）：
hᴱ = 4.1868 · Σ_{j=0..7} Σ_{i=0..7} h_ij xⁱ Tʲ（kJ/kg；x 为摩尔分数）。
与原文图 3 对照：0 °C 最小值 −32.1 kJ/kg @ x=0.45（图读约 −36）；曲线量级与
走势一致。注意 x=1 端 hᴱ ≈ +8.4 kJ/kg ≠ 0（回归未加端点约束，见核验记录 §4.2）。

**(20)–(22) 溶液液体焓**：
吸收剂 h_a = 100 + 4.1868[Cp0·t + ½Cp1·t²]，DMAC：Cp0 = 0.4578，Cp1 = 0.000839（表 5）；
制冷剂 h_r = 100 + 4.1868·Σ_{i=1..7} h_ri tⁱ，系数见表 6；
溶液 h = h_r·ξ + h_a·(1−ξ) + hᴱ。
原文未给 R124 蒸气焓；做完整循环计算时蒸气侧焓须另找 R124 物性来源。

**(23) 纯组分密度**：ρ = Σ_{i=0..3} ρ_i tⁱ（10³ kg/m³；表 7）。

**(25) 混合物密度**（系数表 9）：ρ = Σ_{j=0..3} Σ_{i=0..3} ρ_ij ξⁱ tʲ
（10³ kg/m³；t 为 °C）。测点至 120 °C / 16 bar（平衡态）。
表 9 的 ρ₀₀ 印作 0.95521E+01，本模型按三重旁证订正为 E+00（核验记录 §4.4）。

**(24) 纯组分黏度**：ln η = η0 + η1/(T + η2)（表 8；R124 行原文注明为预测数据）。
DMAC 行印刷值（−16.8400 / 1348.80）经同文式 (26) 与文献值仲裁为 10 倍疑误，
本模型采用 η0 = −1.68400、η1 = 134.880（核验记录 §4.3），代码中显式标注。

**(26) 混合物黏度**（系数表 10）：ln η = Σ_{j=0..3} Σ_{i=0..3} η_ij ξⁱ T^{−j}（T 为 K）。
验算：ξ=1 端与式 (24) 的 R124 行在 20–100 °C 吻合至 0.004 mPa·s。

**露点口径**（滑移图用）：DMAC 沸点 165 °C 对 R124 的 −11 °C，80 °C 时
Psat_DMAC/Psat_R124 ≈ 0.6%，视为不挥发，露点取纯 R124 饱和温度（由 Pref 的
NIST 拟合线反解；2026-10-12 前为式 (15) 反解，本夹三张滑移图已按新线重画）。

**纯 R124 线换源记录（2026-10-12）**：Pref（Python `pref_R124`、C `R124DMAC_PrefR124`、
VBA `Pref_R124DMAC`）已由 Borde 式 (15) 改换为 pure_fluids 所持的 R124 NIST 饱和表
Wagner 型拟合（Tc = 395.428 K、Pc = 36.245 bar、系数 −7.401179377235425 /
1.4613603991162563 / −3.476435267708954 / −1.772232810745864，辖区 −40~110 °C，
对 NIST 表最大偏差 0.111%；与本模块 hgas 同一 NIST 拟合体系）。换源理由：式 (15)
对 NIST 系统性偏低（−5.13%@−30 °C → −1.18%@120 °C，仲裁见工质对公式素材库
《R124 纯工质-NIST 表拟合与 Borde 仲裁》）。DewT 随之改走新线反解（括号 −40~110 °C）。
**分账**：Psol（式 (16)）代码一字未动；式 (15) 仍由 `psat()` 求值器供 DMAC 等
其余组分与 ξ=1 端点对照使用。注意 XiByTsolTdew 的代码亦一字未动，但它内部经
Pref 定压，故其数值随换源移动（见函数清单该行新旧锚并排）——这与 TdewByTsolXi
同线，二者往返自洽不变。新锚：Pref(20 °C) = 3.2724 bar（NIST 表 3.2692）；
DewT(3.2692 bar) = 19.97 °C；TdewByTsolXi(90 °C, 0.4545) = 19.18 °C（旧 20.00）；
AbsVapFlow 新锚见该节。归因验算：同一求解器仅把 Pref 换回式 (15)，旧锚逐位复现，
证明锚点移动只源于纯线换源、非求解器变化。C 版 gcc 复验与 Python 逐位一致；
VBA 同算法移植，未在真实 Excel 中编译。

## 验算

`verify_r124_dmac.py` 八组检查：沸点处蒸气压、式 (16) 两端行为、图 2 读数、
图 3 超额焓曲线、焓参考态、密度两端与图 5、黏度仲裁、以及被篡改的硕士论文
表 2.7 的数值演示（同点得 −1.4×10¹³ bar，原式 2.98 bar）。

> **VBA 函数命名（2026-10-12 改定）**：VBA 公开函数名一律为「属性_工质对」形（如 `Psol_R124DMAC`），因 Excel 工作表公式不接受以 R+数字打头的函数名（R1C1 引用形状，用户实测）。C 版函数名保持 `R124DMAC_*` 原形、Python 版为小写蛇形，三者同算法同数值。由露点与溶液温度求浓度的函数 VBA 名为 `XiByTsolTdew_R124DMAC`。


## 绝热吸收器蒸气流量 AbsVapFlow（2026-10-12 新增）

`AbsVapFlow_R124DMAC(Ts_C, xi_w, ms, Tv_C)`（Python `abs_vap_flow`、C `R124DMAC_AbsVapFlow`）：单程绝热吸收器能吸收的蒸气流量。入口：贫液（流量 ms、温度 Ts_C、浓度 xi_w）与 Tv_C 的饱和 R124 蒸气；吸收器压力取蒸发压力 P＝Pref(Tv_C)（DMAC 不挥发构造）；出口为该压力下的绝热平衡态。方程：出口温度 Tout＝BubbleT(P, xi_r)，浓度由制冷剂平衡 r＝(xi_r − xi_w)/(1 − xi_r)（r＝m_v/ms），绝热焓平衡 hs＋r·hv＝(1＋r)·h(Tout, xi_r)，对 xi_r 扫描＋二分求根。蒸气焓 hv 用 NIST WebBook 饱和表拟合式（与 pure_fluids 的 R124_hV 同一多项式，基准与本模块一致：0 ℃ 液焓＝100；拟合带 −40…110 ℃）。无解（溶液过热吸不动、或超出辖区 ξ≤0.95）时 VBA 返 Empty、C 返 NAN、Python 返 None。

验算（双绝热腔扫算表 R124–DMAC 页 Tg＝90 ℃ 档的吸收器）：输入 Ts＝20 ℃、xi_w＝0.4544676、ms＝100、Tv＝−20 ℃，换源前（式 (15) 压力线）得 m_v＝10.1041、Tout＝28.350 ℃、xi_r＝0.504530；扫算表为 10.1351 / 28.331 ℃ / 0.504670；当时 m_v 差 −0.31% 源于蒸气焓出处不同（扫算表用 CoolProp＋δ＝247.69，本函数用 NIST 拟合 248.53，Δ＝＋0.83 kJ/kg），其余口径（Borde 泡点/溶液焓/压力线）完全一致。**2026-10-12 纯线换源后新锚**（同输入）：m_v＝11.1846、Tout＝29.159 ℃、xi_r＝0.509345——与扫算表的差自此还含压力线换源一项（Tv＝−20 ℃ 处 Pref 由式 (15) 的 0.6824 bar 升至 NIST 线 0.7149 bar，+4.75%，吸收压力升高故 m_v 增大）；归因验算（同求解器换回式 (15) Pref）逐位复现旧锚 10.1041 / 28.350 / 0.504530，证明移动只源于换源。追加对照点（Ts, xi_w, ms, Tv）→ 新锚（旧锚）：(20, 0.4544676, 100, 0)→33.2915 / 44.607 / 0.590722（旧 32.1306 / 43.945 / 0.587126）；(20, 0.4544676, 100, 20)→59.4207 / 59.479 / 0.657803（旧 58.1135 / 58.915 / 0.654974）；(30, 0.4544676, 100, −20)→3.6899 / 32.933 / 0.473881（旧 2.6670 / 32.140 / 0.468639）；(10, 0.4544676, 100, −20)→18.7707 / 25.748 / 0.540684（旧 17.6422 / 24.934 / 0.536278）；(20, 0.30, 100, −20)→23.0899 / 37.520 / 0.431310（旧 21.8763 / 36.761 / 0.425647）。C 与 Python 逐位相同；VBA 同算法移植，未在真实 Excel 编译。

## 2026-10-12 全库命名统一与新增函数

本节记录 2026-10-12 的全库统一命名与两个新增必备函数。旧名不留别名、彻底退场。

**命名分账**：`Psol` = 溶液表面（平衡）蒸气压（原泡点压力函数），`Pref` = 纯制冷剂饱和压力，两者分账、不可互换。纯制冷剂饱和液焓为 `hliq`、饱和气焓为 `hgas`、潜热 `hlat = hgas - hliq`（两焓同基准才可减）；溶液焓为 `hsol`，与纯制冷剂的 hliq 分账。

### 新增：TdewByTsolXi（由溶液温度与浓度求露点温度）

定义（全库统一）：`TdewByTsolXi(Tsol, xi) = 模块 Tsat(Psol(Tsol, xi))`；本模块即与已有 DewT 复合：`dew_T(psol(T_C, xi))`（纯 R124 线为 Pref 的 NIST 拟合线，与 DewT 同源；2026-10-12 前为 Borde 式 (15)，见换源记录）。Python `tdew_by_tsol_xi`、C `R124DMAC_TdewByTsolXi`、VBA `TdewByTsolXi_R124DMAC`。单位 °C，xi 为 R124 质量分数，P 为 bar。DMAC 视为不挥发。无解约定随 dew_T：Python 返 None、C 返 NAN、VBA 返 Empty。纯端锚：xi=1、T=40 °C 时 Tdew = 44.88 °C（偏差 +4.88 K；换源前旧线 45.64 °C / +5.64 K）——这是式 (16) 在 xi=1 处相对纯线已知失配（对 NIST 线 40 °C 处 Psol/Pref = 1.142，即 +14%）的直接传导，非新函数误差。

### 新增：TsolByHsol（hsol 的反函数）

`TsolByHsol(h, xi)` 满足 `hsol(TsolByHsol(h, xi), xi) = h`：对 hsol 在求解括号 T ∈ [−40, 150] °C 内二分 100 次（hsol 在固定 xi 下随 T 单调增）。Python `tsol_by_hsol`、C `R124DMAC_TsolByHsol`、VBA `TsolByHsol_R124DMAC`。h 超值域时：Python 返 None、C 返 NAN、VBA 返 Empty。验算往返误差 < 1e-6 K 量级。AbsVapFlow 内部取吸收压力已改走 `Pref`、溶液焓改走 `hsol`、蒸气焓改走 `hgas`，改名当时数值不变（锚点复核：m_v = 10.1041、Tout = 28.350 °C、xi_r = 0.504530；该锚为 2026-10-12 纯线换源前值，换源后新锚见 AbsVapFlow 节）。
